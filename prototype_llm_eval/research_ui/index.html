Question appropriateness review (human)

Inspect each frozen benchmark task against the intended generation template (beginner-level, concept-aligned, five independently markable subtasks, clear wording). Labels save to evaluation/results/question_generation_review.csv via POST /api/research/question-review.

Template expectations

Appropriateness criteria:

  • Matches selected concept
  • Suitable for intended learner level (beginner)
  • Exactly five clear subtasks
  • Subtasks are independently markable
  • Question wording is understandable

This is not string-matching against another gold question file — it is human judgement vs the rubric above.
